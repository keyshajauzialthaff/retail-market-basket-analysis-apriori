# retail-market-basket-analysis-apriori
Retail Market Basket Analysis using Python and the Apriori algorithm (mlxtend). Includes data preprocessing, descriptive analytics with interactive Plotly visualizers, association rules mining, and product bundling recommendations.

# Retail Market Basket Analysis (Apriori Algorithm)

Proyek *Data Mining* untuk menganalisis pola pembelian konsumen (*Market Basket Analysis*) pada data transaksi ritel menggunakan bahasa pemrograman Python dan Algoritma Apriori.

## Fitur Utama
* **Preprocessing & Transformasi Data**: Pembersihan data, penanganan nilai kosong/duplikat, hingga transformasi *One-Hot Encoding* menggunakan library `mlxtend`.
* **Statistik Deskriptif & Visualisasi**: Analisis distribusi jumlah item per transaksi, metode pembayaran, jenis toko (*store type*), dan musim menggunakan Plotly dan Matplotlib.
* **Algoritma Apriori**: Pencarian *frequent itemsets* dan pembentukan aturan asosiasi (*association rules*) berdasarkan metrik *support*, *confidence*, dan *lift*.
* **Visualisasi Lanjutan**: Pembuatan *Scatter Plot* interaktif dan *Network Graph* hubungan antar produk.
* **Rekomendasi Bundling**: Menghasilkan rekomendasi produk paket penjualan (*bundling*) berdasarkan aturan asosiasi terkuat.


* **Bahasa**: Python
* **Pustaka (Libraries)**: Pandas, Mlxtend, Plotly, NetworkX, Matplotlib
* **Platform**: Google Colaboratory / Jupyter Notebook
